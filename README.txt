Block 8 Midterm 1 Practice Questions (Cardiovascular)
UNR Med Class of 2029

WHAT'S INCLUDED
- Practice Test 1 and Practice Test 2: 55 questions each, with the same number of
  questions per session as the Midterm 1 blueprint. Both are drawn from the
  high-yield, board-style questions.
- Extra Practice: 148 more questions, including the detail-level ones. Use these
  after the two tests.
- 12 EKG questions with tracings (4 in Test 1, 3 in Test 2, 5 in Extra Practice).
  They are labeled "EKG Reading" and take the place of blueprint questions from the
  EKG, Arrhythmia, Chest Pain Cases and Pericardial Disease sessions.

HOW TO RUN
1. Install Python 3 from python.org if you don't have it.
2. Install Streamlit once:
     Mac:      pip3 install streamlit
     Windows:  py -m pip install streamlit
3. Unzip this folder. Open Terminal (Mac) or Command Prompt (Windows), type cd and a
   space, drag the folder into the window, and press Enter.
4. Start the app:
     Mac:      python3 -m streamlit run app_blk8.py
     Windows:  py -m streamlit run app_blk8.py
   It opens in your browser. Keep the images folder next to the app.

USING IT
- Pick a question set in the sidebar. Switching sets starts a fresh attempt.
- Exam Mode hides answers until you finish, like the real exam. Exam pacing is
  90 seconds per question, about 83 minutes per test.
- Questions and answer choices are shuffled every run. Enter a seed number to
  reload a specific order.
- The sidebar dropdown filters by lecture.
